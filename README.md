# GRAFITYGATE

**場所に、記憶の扉を。**

現実の場所や物に、写真・言葉・声・映像・AR の作品を残せる iPhone アプリです。
友達がその場所を訪れたとき、または数年後の自分が戻ってきたとき、残された GATE（記憶の扉）に出会えます。

## いまできること

- AR のカメラを目の前の場所・物に向けて「ここで開く」→ 位置と景色が合うと、扉が現れて開く
- 扉は厚みのある石のアーチ。光の縁・接地の影があり、開くと向こうに思い出の写真と光の粒が見える
- GATE を作る：3 方向から写す → 名前など → 扉を置く所を押す → まわりを見回して「場所の記憶」を保存
- 友達の iPhone では、場所の記憶で作った人と同じ位置に扉を出す（見つからなければ目の前のおおよその位置）
- 100m 以内の GATE を地図で見つける
- 入場中（20 分）に、写真付きのグラフィティを 1 枚残す。同じ GATE には 12 時間あけて
- 扉が開いたら、扉のまわりに AR の作品を置ける（写真パネル・光る文字・花びら・光の玉。1 人 1 つの GATE に 3 つまで）。
  作品は扉が基準の位置に残るので、場所の記憶で扉が同じ位置に出れば、作品も同じ位置に出る
- 作品は、近づく・画面で押す・**手をのばして触れる**と動く（光る・ゆれる・波紋・はじける・はねる）。
  手は iPhone の中だけで見分け、カメラの映像はどこにも送らない
- GATE の中は「記憶／思い出／掲示板／手紙」に分かれる
  - 思い出：何枚かの写真を 1 つにまとめ、一緒にいた友達を仲間に入れると、それぞれが写真を足せる
  - 掲示板：話題（思い出話・質問・お知らせ）と返信。未読の印、作った人のピン留め
  - 手紙・タイムカプセル：未来の自分や友達へ。「この日を過ぎたら」「ここに来たら」開ける。閉じているあいだは、あることだけが分かる
- 保存、図鑑（扉を開けた GATE が集まる。選んだものだけ友達に見せる）、いいね
- 通報・ブロック（Lyric Path と共通）、自分のデータの書き出し、アカウントの削除
- 友達（お互いにフォロー）の新着を 24 時間見る。中身は現地で扉を開けたときだけ

景色を確かめるときは、写真そのものではなく、写真から作った「特徴」（数の並び）と位置だけを送ります。
グラフィティや表紙の写真は、位置などの付加情報を消してから送ります。

## フォルダ

| 場所 | 中身 |
| --- | --- |
| `App/` | iPhone アプリ（SwiftUI・iOS 17 以上）。`project.yml` から XcodeGen で Xcode のプロジェクトを作る |
| `supabase/migrations/` | サーバー（Supabase）の表とルール。SQL Editor に貼って実行する |
| `supabase/tests/` | サーバーのルールのテスト（`bash supabase/tests/run.sh`。PostgreSQL が要る） |
| `.github/workflows/ios.yml` | GitHub のクラウド Mac での組み立てと、TestFlight への送信 |
| `docs/SETUP.md` | はじめて動かすときの準備 |

## 組み立て

Mac は要りません。`main` に push すると GitHub Actions が、サーバーのルールのテストと、署名なしの組み立てを行います。
TestFlight に送るときは、Actions の「iOS」→「Run workflow」で「TestFlight に送る」を選びます（準備は `docs/SETUP.md`）。
